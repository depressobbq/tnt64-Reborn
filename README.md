# The New Tetris: Tournament Edition (TNT-TE)

*The New Tetris: Tournament Edition* is a competitive community-focused fork of the *The New Tetris* (N64) native PC recompilation.

> **Status:** Active Development (WIP)

### Planned & In-Progress Features:
- **Seeded Runs:** Configurable RNG seeds for practice, daily challenges, and synchronized tournament races.
- **Competitive Sidebar HUD:** Live on-screen display of **True Lines Cleared**, **LPM (Lines Per Minute)**, and **Cubes/Blocks Formed**.
- **Automated Score Sharing:** Direct game-over score submissions via Discord Webhooks and anti-cheat verified result strings.

*Detailed documentation and build instructions will be updated upon initial release.*
